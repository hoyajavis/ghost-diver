# Curriculum Extension Plan

This extension takes your "Ghost Diver" into the Deep Sub-Strata (Floors 51–100). At this depth, the Monolith’s security isn't just checking calculations; it's checking logic systems and functions.
To handle Grade 7 and 8 math, we transition from "Arithmetic" to "Modeling."

## 🛰️ The Deep Sub-Strata (Floors 51–100)

### Tier 11: Floors 51–55 (Proportional Relationships)
* Type 1: Identifying the Constant of Proportionality (k) from tables.
* Type 2: Solving multi-step Ratio and Percentage problems (Tax, Tip, Markup).
* Type 3: Simple Interest calculations (I = Prt).
* Conceptual Check: Recognizing the difference between a proportional relationship and a linear one that doesn't pass through (0, 0).

### Tier 12: Floors 56–60 (Rational Number Operations)
* Type 1: Adding and Subtracting positive and negative fractions/decimals.
* Type 2: Multiplying and Dividing negative fractions and mixed numbers.
* Type 3: Multi-step operations with Rational Numbers.
* Conceptual Check: Understanding why a negative times a negative results in a positive in the system logic.

### Tier 13: Floors 61–65 (Advanced Expressions & Equations)
* Type 1: Factoring linear expressions (e.g., 3x + 12 = 3(x + 4)).
* Type 2: Solving two-step Equations with negative coefficients.
* Type 3: Solving and graphing multi-step Inequalities.
* Conceptual Check: Distinguishing between an algebraic expression and an equation.

### Tier 14: Floors 66–70 (Statistics & Probability)
* Type 1: Calculating Theoretical vs. Experimental Probability.
* Type 2: Determining Sample Spaces (Tree Diagrams and Tables).
* Type 3: Comparing two populations using Mean Absolute Deviation (MAD).
* Conceptual Check: Predicting long-term outcomes based on small data samples.

### Tier 15: Floors 71–75 (Scale & 3D Geometry)
* Type 1: Finding actual dimensions from Scale Drawings.
* Type 2: Circumference and Area of Circles.
* Type 3: Volume and Surface Area of Right Prisms and Pyramids.
* Conceptual Check: Understanding how the area of a circle relates to its radius squared.

### Tier 16: Floors 76–80 (Roots & Scientific Notation)
* Type 1: Perfect Squares and Square Roots (\sqrt{x}).
* Type 2: Perfect Cubes and Cube Roots (\sqrt[3]{x}).
* Type 3: Converting standard numbers to Scientific Notation and back.
* Conceptual Check: Estimating the location of irrational square roots (like \sqrt{20}) on a number line.

### Tier 17: Floors 81–85 (Linear Functions)
* Type 1: Calculating Slope (m) from two points.
* Type 2: Writing equations in Slope-Intercept Form (y = mx + b).
* Type 3: Identifying functions vs. relations (The Vertical Line Test).
* Conceptual Check: Interpreting "Rate of Change" as the physical steepness of a data line.

### Tier 18: Floors 86–90 (Systems of Equations)
* Type 1: Solving Systems by Graphing (Finding the intersection).
* Type 2: Solving Systems by Substitution.
* Type 3: Determining if a system has one, zero, or infinite solutions.
* Conceptual Check: What it means for two "code streams" (lines) to occupy the same point.

### Tier 19: Floors 91–95 (Geometric Transformations)
* Type 1: Translations (Sliding points on a grid).
* Type 2: Reflections (Flipping over x or y axes).
* Type 3: Rotations (Turning 90^{\circ} or 180^{\circ} around the origin).
* Type 4: Dilations (Resizing using a scale factor).
* Conceptual Check: Congruency vs. Similarity after a transformation.

### Tier 20: Floors 96–100 (The Root Breach)
* Type 1: Pythagorean Theorem (a^2 + b^2 = c^2) to find missing sides.
* Type 2: Distance between two points on a Coordinate Plane.
* Type 3: Volume of Cones, Cylinders, and Spheres.
* Type 4: Interpreting Scatter Plots and Lines of Best Fit.
* Conceptual Check: Using the "Final Exam" logic to synthesize all previous tiers.

## 🛠️ Brainstorming User Input for Higher Grades

To handle these advanced ciphers, the "Hacker Terminal" needs more than just a numpad:

1. **The Variable Toggle (The "Algebra Bar")**
 * UI: A small row above the numpad with x, y, and z.
 * Use: Essential for writing expressions in Tier 13 and Tier 17.
 * Interaction: Tapping x puts the variable into the input line.

2. **Radical & Exponent Modifiers**
 * UI: A \sqrt{} button and a x^y button.
 * Interaction: Tapping \sqrt{} creates a box inside a radical. Tapping x^y moves the cursor to a superscript position (like writing 10^5 in Tier 16).

3. **The Functional Slider (Slope-Intercept)**
 * UI: Instead of typing, for Tier 17 (Slope), give the player a line on a graph with two "handles."
 * Interaction: The player drags the handles to match a specific slope or y-intercept provided by the Sentinel. This makes the math "tactile" and visual.

4. **Transformation Controls (Arrow Keys + Rotator)**
 * UI: For Tier 19, a set of directional arrows for "Translate" and a clockwise/counter-clockwise toggle for "Rotate."
 * Interaction: The Sentinel shows a "Ghost Image" of a shape, and the player must move their "Active Shape" into the correct position using these controls.

5. **Multi-Line Terminal**
 * UI: For Tier 18 (Systems), the input field needs two lines.
 * Interaction: The player solves the first equation, hits "Down" or "Next," and solves the second. The battle only ends when both "intercepts" are found.
