# 50-Floor Math Curriculum Plan

This is the organized 50-floor math curriculum, structured into ten tiers of five floors each. This layout maintains the extraction point every five floors while ensuring a smooth pedagogical progression from 4th-grade foundations to 6th-grade mastery.

## Tier 1: Floors 1–5
* Problem Type 1: Base-10 Place Value shifts (Multiplying/Dividing by 10, 100, and 1,000).
* Problem Type 2: Rounding whole numbers to the nearest 10, 100, or 1,000.
* Problem Type 3: Multi-digit integer Addition.
* Problem Type 4: Multi-digit integer Subtraction.
* Conceptual Check: The role of zero as a placeholder in multi-digit numbers.

## Tier 2: Floors 6–10
* Problem Type 1: 2-digit by 1-digit Multiplication.
* Problem Type 2: Identifying all Factors of a given number.
* Problem Type 3: Identifying Multiples of a given number.
* Problem Type 4: Identifying Prime vs. Composite numbers.
* Conceptual Check: The mathematical distinction between factors and multiples.

## Tier 3: Floors 11–15
* Problem Type 1: 2-digit by 2-digit Multiplication.
* Problem Type 2: Long Division (Standard algorithm without remainders).
* Problem Type 3: Interpretation of remainders in word problems (Rounding up vs. Dropping).
* Conceptual Check: The inverse relationship between multiplication and division.

## Tier 4: Floors 16–20
* Problem Type 1: Generating Equivalent Fractions and simplifying to lowest terms.
* Problem Type 2: Comparing Fractions using symbols (<, >, =).
* Problem Type 3: Addition with Like Denominators.
* Problem Type 4: Subtraction with Like Denominators.
* Conceptual Check: The physical representation of the numerator vs. the denominator.

## Tier 5: Floors 21–25
* Problem Type 1: Addition with Unlike Denominators.
* Problem Type 2: Subtraction with Unlike Denominators.
* Problem Type 3: Multiplying Fractions by whole numbers.
* Problem Type 4: Calculating Volume of rectangular prisms (V = l \cdot w \cdot h).
* Problem Type 5: Unit Conversions (Length and Weight).
* Conceptual Check: How 2D Area scales into 3D Volume.

## Tier 6: Floors 26–30
* Problem Type 1: Multi-digit Decimal Addition and Subtraction.
* Problem Type 2: Decimal Multiplication and Division.
* Problem Type 3: Converting Fractions to Decimals.
* Problem Type 4: Converting Decimals to Fractions.
* Conceptual Check: Logic behind moving the decimal point during various operations.

## Tier 7: Floors 31–35
* Problem Type 1: Expressing basic Ratios (a:b).
* Problem Type 2: Calculating Unit Rates (Value per single unit).
* Problem Type 3: Calculating Percentages of a whole number.
* Conceptual Check: Recognizing verbal identifiers for rates (e.g., "per," "each").

## Tier 8: Floors 36–40
* Problem Type 1: Positive and Negative Integer Addition.
* Problem Type 2: Positive and Negative Integer Subtraction.
* Problem Type 3: Absolute Value calculations (|-x|).
* Problem Type 4: Plotting points on a 4-Quadrant Coordinate Plane.
* Conceptual Check: Using Zero as a relative reference point (e.g., Sea Level or Temperature).

## Tier 9: Floors 41–45
* Problem Type 1: Exponents (Squares and Cubes).
* Problem Type 2: Order of Operations (PEMDAS protocols).
* Problem Type 3: Evaluating Variable Expressions (e.g., 3x + 5 given x = n).
* Conceptual Check: The necessity of operational priority and parentheses in logic.

## Tier 10: Floors 46–50
* Problem Type 1: Solving One-step Algebraic Equations.
* Problem Type 2: Solving One-step Inequalities (x > n).
* Problem Type 3: Area of Triangles and complex Polygons.
* Problem Type 4: Calculating Mean, Median, Mode, and Range.
* Conceptual Check: The impact of outliers on statistical measures (Mean vs. Median).
